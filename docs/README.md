# train —— 多点位单模型缺陷分割训练

把一个产品**全部点位**的图像训练成**一个**缺陷分割模型。  
训练靠在底图上**现场贴合成缺陷**制造正样本；真实 NG 图抽 **20% 作独立考卷**（整图永不进训练），每轮用来考试选型与人工验收。

```
define_masks 分区定义 ({基准图}.json)     ─┐
datasets/{产品}/assets 缺陷素材 (砂眼/划痕) ─┼─→ train ─→ models/{产品}/ (best 权重 + deploy/ 推理包)
datasets/{产品}/{点位} 现场原图 (*.bmp+.tmp)─┘
```

> **全局格式约定（全工程仓库统一遵守）**：
> - **人工维护的配置文件使用 `.jsonc`**（支持 `//` 注释，如 `config/app_config.jsonc`、`assets.jsonc`）；
> - **代码自动生成的产物使用 `.json`**（标准纯 JSON 无注释，字段说明写在 `README.md` 中，如 `{基准图名}.json`、`deploy/manifest.json`）。

## 一、 快速上手（训前准备与启动）

### 1. 训前要准备的 4 件事（全部放在 `../datasets/{产品}/`，不进 GitLab）

| 步骤 | 要做的事 | 存放位置 | 关键检查项 |
| :--- | :--- | :--- | :--- |
| **① 准备缺陷资产** | 放入缺陷小图 `{名}.png` 与同名掩码 `{名}_mask.png`（支持子目录分组） | `datasets/{产品}/assets/{缺陷类型}/` | 单通道灰度 PNG；自动按同名 `*_mask.png` 配对识别（无需 `manifest.csv`，自动跳过预览图/文本等） |
| **② 放入现场原图** | 每个点位平铺放入 `*.bmp`；真缺陷图旁放同名 `.bmp.tmp` 标注 | `datasets/{产品}/{点位}/` | **所有点位图像分辨率必须一致**；`.tmp` 中只要 `label != "排除"`（如 `"砂眼"`、`"划痕"`）即视为缺陷 NG 图 |
| **③ 画出分区蒙版** | 用 `define_masks` 打开点位基准图，画好分区并保存 | `datasets/{产品}/{点位}/{基准图名}.json` | 必须包含 **`domain`** 分区（对齐依据）及待检分区（如 `"加工面"`） |
| **④ 绑定分区与资产** | 手写 `assets.jsonc`，指定哪个分区贴哪类缺陷及尺寸范围 | `datasets/{产品}/{点位}/assets.jsonc` | `dir` 从点位目录出发指向 `../assets/{类型}` |

### 2. 启动训练与常用命令

```bash
# 默认启动（datasets/ 下只有 1 个产品时零参数直接跑；自动开 8300 监控页）
uv run train

# 指定产品 / 只训部分点位 / 从已有 best 权重迁移精调
uv run train --product HT12
uv run train --product HT12 --points JXFB-1-P1,JXFB-1-P5
uv run train --product HT12 --base models/HT12/best_int1200_ep10.pth
```

| 命令行参数 | 缺省值 | 说明 |
| :--- | :--- | :--- |
| `--product` | 唯一产品自动选中 | `datasets/` 下有多个产品时必须显式指定 |
| `--epochs` | `20` | 最大训练轮数（达到早停条件会提前结束） |
| `--base` | `pretrained/pretrained.pth.tar` | 起步权重（官方骨干，或指向任意 `best_*.pth` 做迁移） |
| `--points` | 全部点位 | 只训指定点位，多个点位用逗号分隔 |
| `--monitor_only` | 关 | 仅启动 `http://服务器IP:8300` 监控网页，不拉起训练 |

## 二、 目录结构

`datasets/`（产品素材库，不进 Git）与 `train/`（代码与机器产物）**平级摆放**：

```
supervised_apps/
 ├─ datasets/                          # 【产品素材库 · 不进 GitLab · 机器只读】
 │   └─ {产品}/                        # 例如 HT12/ (一产品一目录，内含 assets 与各点位)
 │       ├─ assets/                    # 该产品专属缺陷素材库 (自动递归扫描配对)
 │       │   ├─ 砂眼/                  #   ├─ *.png + *_mask.png (自动忽略无配对文件)
 │       │   └─ 划痕/                  #   └─ *.png + *_mask.png
 │       └─ {点位}/                    # 点位目录 (体检时自动跳过同级 assets 目录)
 │           ├─ {基准图名}.json        # define_masks 产出的分区定义 (代码生成 · 标准 JSON)
 │           ├─ assets.jsonc           # 分区 × 资产绑定 (人工维护 · JSONC)
 │           └─ *.bmp                  # 平铺原图 (带同名 .bmp.tmp = 有标注)
 │
 └─ train/                             # 【训练仓库】
     ├─ config/app_config.jsonc        # 全局常量 (人工维护 · JSONC): tile_size / max_images_per_point / seed / web_port
     ├─ pretrained/pretrained.pth.tar  # 官方预训练骨干权重
     ├─ src/train/                     # 训练与监控引擎代码
     ├─ .tmp/{产品}/                   # 机器中间产物 (对齐缓存 / 逐轮权重 / 日志, 随时可删)
     └─ models/{产品}/                 # 最终交付物
         ├─ best_int{交集}_ep{轮}.pth  # 唯一最优模型权重
         └─ deploy/                    # 推理要素包 (按点位子目录隔离 + manifest.json)
```

## 三、 训练事件线（全景树）

```
uv run train
 │
 ├─ 0. 素材体检 (checkup)
 │      └─ 校验 {基准图}.json / 基准图 / 资产配对(*.png+*_mask.png) / 全点位同分辨率 / 标注合法性，不合格直接退出
 │
 ├─ 1. 整图对齐 (align)
 │      └─ 用 domain 分区角点解算 8 自由度单应 H → 全部原图回贴到基准图坐标系 → 存 .tmp 对齐缓存
 │
 ├─ 2. 固定分卷 (split_roster)
 │      ├─ 带缺陷标注(label!="排除") NG 图 ──┬─ 20% → 独立考卷 (整图永不进训练池)
 │      │                                   └─ 80% → 借作训练底图 (真缺陷区标 255 忽略)
 │      └─ 无缺陷 OK 图 + 80% NG 底图 → 训练池 ──(8:2)──→ 训练集 / 验证集 (val)
 │
 ├─ 3. Epoch 循环 (上限 20 轮 | 早停: 练满 8 轮后 val_loss 连续 4 轮不降)
 │      │
 │      ├─ [A. 在线切块与合成缺陷] (50% 纯净块 + 50% 贴缺陷块，每块 5 变体)
 │      │    ├─ 1. 切块：网格裁 512×512 (训练集坐标随机抖动 ±stride/2，验证集固定网格)
 │      │    ├─ 2. 抽素材去背景：内存中将掩码外 (~mask) 抹平为自身灰度中位数，贴边素材自动垫 1px 背景边 (磁盘原文件不动)
 │      │    ├─ 3. 缩放：在 [min, max] 内按「对数均匀分布」抽目标尺寸并缩放素材
 │      │    ├─ 4. 变换：50% 水平翻转 → 亮度 ×(0.8~1.1) → 0~360° 随机旋转 (边缘复制填充)
 │      │    ├─ 5. 锚点：在分区有效像素内随机落点 (自动避开底图已有的真实缺陷)
 │      │    ├─ 6. 泊松贴图：掩码矩形外扩 5~7px 送入 NORMAL_CLONE 求解泊松场，再按原掩码 1px 柔边写回底图
 │      │    ├─ 7. 截断与复检：贴完裁回 512 块 → 检测区外恢复原底图 → 复检尺寸 ∈[min,max] 且可见度 ≥4
 │      │    └─ 8. 打 GT 标签：回缩用原始未外扩掩码标 1 | 正常背景标 0 | 检测区外及底图真缺陷外扩 4px 标 255
 │      │
 │      ├─ [B. 模型训练] EfficientViT-SAM L1 + LoRA + 级联浅层跳连分割头 (Focal+Dice, bf16, 向量化 EMA)
 │      ├─ [C. 验证早停] 固定 val 题集全像素稠密算 val_loss → 决定是否触发早停
 │      └─ [D. 考卷考试] 独立考卷切块推理 (重叠带线性加权窗拼接) → 阈值 0.5 算与真值总交集像素数
 │
 └─ 4. 交付落盘 (deploy)
        └─ 总交集创新高时更新唯一 best 权重，并按点位生成 deploy/{点位}/ 要素包与 manifest.json
```

## 四、 核心操作说明：怎么做 & 为什么这么做

### 0. 从 0 到 1：缺陷轮廓（Mask）全生命周期操作时间线（速查表）

从人工画框到最终喂给分割模型训练，缺陷轮廓在整套流水线中先后经历以下 **6 次操作**：

| 时间顺序 | 所在阶段 | 对谁操作 | 具体动作（改多大） | 一句话原因 |
| :---: | :--- | :--- | :--- | :--- |
| **①** | **人工标注**<br>(`define_masks`) | 原始大图 `.tmp` 多边形 | **原样紧贴轮廓（`0px`）** | 标出真实缺陷的精确物理边界 $M_{\text{raw}}$。 |
| **②** | **LoRA 切片**<br>(`synth_assets` P1) | 512 切片上的真缺陷轮廓 | **一分为二**：<br>· 形态模板存**原样** $M_{\text{raw}}$<br>· 训练掩码**自适应外扩 `8~16px`** | · 原样留作后续重绘的“印章”真值 $M_{\text{GT}}$；<br>· 外扩 `8~16px` 让 SD 重绘区包含一圈背景过渡带，学懂缺陷与金属底纹如何自然接缝。 |
| **③** | **合成重绘与落盘**<br>(`synth_assets` P3/P4) | 印章模板 $M_{\text{GT}}$ | · **送 SD 重绘前**：外扩 **`8~16px`**<br>· **裁剪落盘时**：按未外扩 $M_{\text{GT}}$ 外接框 **留 `6px` 边距**裁小图 | · 重绘时给 SD 留融合缓冲带；<br>· 落盘时掩码缩回精确真值 $M_{\text{GT}}$（`*_mask.png`），但小图四周多留 `6px` 背景余量供下游泊松融合使用。 |
| **④** | **训练加载与旋转**<br>(`train` `assets.py`) | 资产小图 `(patch, mask)` | **先抹平背景 → 贴边垫 `1px` → 缩放旋转**：<br>· 内存中把 `~mask` 抹平为背景灰度中位数<br>· 若 `mask` 贴边则向外垫 **`1px`** 背景色 | · 抹平异源背景假纹理，保留纯正的「缺陷与背景相对色差」；<br>· 垫 `1px` 防止旋转（`BORDER_REPLICATE`）把贴边缺陷像素拉伸成直角三角伪影。 |
| **⑤** | **泊松融合与打标签**<br>(`train` `paste_poisson`) | 旋转后的连续掩码 `m_float` | **先外扩求解 → 再按原掩码柔边回写 → 原掩码打标签**：<br>· `m = (m_float > 0.4)` 矩形外扩 **`5~7px`** 送 `seamlessClone`<br>· 结果按 `m_float`（**`1px` 柔边**）仅把缺陷本体写回底图<br>· GT 标签取 **`m_float > 0.25`** 标 `1` | · OpenCV `seamlessClone` 底层会暗中做 `4px` 矩形腐蚀，必须外扩 `5~7px` 才能保住缺陷边缘梯度不被啃掉；<br>· 仅把缺陷本体柔边写回底图，外围 100% 保持原底图真实刀纹；<br>· GT 标签不外扩，模型预测边缘才精准不发胖。 |
| **⑥** | **底图真缺陷屏蔽**<br>(`train` `_annot_tile`) | 训练底图自带的 `.tmp` 标注 | 多边形向外扩 **`4px`** 后标 `255`（忽略） | 人工标注偏紧，外扩 `4px` 把真缺陷边缘过渡带一并屏蔽（不教不罚），防止被当成正常背景 `0` 误导模型。 |

### 1. 分卷与底图防误导机制

| 关键操作 | 怎么做（具体动作） | 为什么这么做（设计目的） |
| :--- | :--- | :--- |
| **20% 考卷独立** | 带缺陷标注（`label != "排除"`）的 NG 图中固定抽出 20% 只当考卷，整图不进训练池 | 保证考试选型（best）面对的是模型从未见过的真实缺陷图，防止作弊。 |
| **80% NG 图借底** | 其余 80% NG 图放进训练池当底图用，但把图上原有的标注区置为 `255`（忽略），且合成缺陷避开该区域 | 现场采集的图宝贵，借用 NG 图上大片无缺陷的正常铝面来贴合成缺陷；原真缺陷区标 `255` 在算 Loss 时直接跳过，**不教也不罚**，不会误导模型。 |
| **底图真缺陷外扩 4px** | 底图上的 `.tmp` 人工标注多边形往外扩 `4px` 后再标 `255` | 人工画框往往紧贴缺陷内侧，外圈 2~4px 其实是缺陷过渡边；如果不外扩会被当成正常背景 `0` 训练，导致模型不敢报真缺陷边缘。 |
| **训练集切块随机抖动** | 训练切块在固定网格上随机偏移 `±stride/2`；验证集不偏移 | 防止工件固定结构（孔位、边角）永远出现在图块同一坐标，避免模型死记硬背位置。 |

### 2. 缺陷合成与泊松融合机制（重点）

| 关键操作 | 怎么做（具体动作） | 为什么这么做（设计目的） |
| :--- | :--- | :--- |
| **内存去背景与贴边垫宽** | 读取素材后（不改磁盘原图），在内存中将掩码外（`~mask`）全部抹平为自身灰度中位数；若掩码触碰图像边框则自动外垫 `1px` 背景色 | 消除异源背景假纹理梯度，锁住纯正的「缺陷—背景色差」；贴边垫 `1px` 防止后续 `0~360°` 旋转时边缘复制填充把缺陷像素拉伸到半个外接矩形。 |
| **对数均匀抽尺寸** | 在 `[min, max]` 间按对数均匀抽目标大小（如 `400~2000` 与 `2000~10000` 概率相近） | 普通均匀抽样平均值在 `5200`，会让大斑块占满训练集；对数抽样保证**细小砂眼/短划痕**有充足比例。 |
| **掩码外扩 5~7px 求解 + 1px 柔边回写** | 泊松贴图前先把掩码用矩形核外扩 `5~7px` 送入 `NORMAL_CLONE` 求解，最后按原掩码 `m_float`（`1px` 高斯柔边）仅把缺陷本体融合回底图 | OpenCV `seamlessClone` 底层会对掩码清零 `1px` 边框再做 3 次 `3×3` 矩形腐蚀（共内缩 `4px`）；外扩 `5~7px` 确保腐蚀后仍完整包裹缺陷边界梯度，再按原掩码柔边写回，既锁住 100% 缺陷对比度，又让掩码外 100% 保留原底图真实刀纹。 |
| **超界复制边缘垫宽** | 如果外扩 `5~7px` 时超出了素材小图的四周边框，自动把素材最边缘像素往外复制垫够宽度 | 防止缺陷在外扩时触碰画布边界报错，保证缓冲带完整。 |
| **带四周上下文画布贴图** | 先从整图中多裁一圈真实背景（`512 + 四周 margin`），把完整缺陷泊松贴上去，再裁回 `512×512` 块 | 避免跨块边界的缺陷在贴图前被一刀切平（切平处做泊松融合会发虚），同时让模型学会识别正好压在切块边界上的缺陷。 |
| **GT 标签回缩原掩码** | 贴图用外扩 `5~7px` 的大掩码求解，但生成的训练真值标签（GT）**只标原始未外扩掩码为 `1`**（外扩圈仍标 `0`） | 外扩圈只是泊松求解的边界缓冲带，不是缺陷本体；GT 保持原始掩码大小，模型预测出的缺陷边缘才精准不发胖。 |
| **先融合、后按检测区截断** | 完整缺陷泊松融合后，再把超出检测区（如加工面外）的像素还原成原底图，并复检剩余面积/长度仍在 `[min, max]` 内 | 让贴在加工面边缘的缺陷呈现自然的「到边界戛然而止」效果，不会在检测区边缘产生一圈假融合接缝。 |
| **可见度复检（≥ 4 灰度级）** | 检查贴完后缺陷区与原底图的平均灰度差，不足 `4.0` 则作废重抽 | 防止暗底图把缺陷融没了（肉眼看不见却硬标 `1`），杜绝「透明正样本」毒化模型。 |

### 3. 验证、考试与交付机制

| 关键操作 | 怎么做（具体动作） | 为什么这么做（设计目的） |
| :--- | :--- | :--- |
| **全像素确定性 `val_loss`** | 验证集不走随机点采样，而是对块内全部有效像素（`!= 255`）算 Focal + Dice | 保证每轮考试尺子完全固定、无随机波动，早停判断真实可靠。 |
| **切块推理重叠窗拼接** | 考卷切块（步长 `384`，重叠 `128px`）推理后，重叠区按线性渐变权重窗交叉淡入拼回整图 | 块边缘缺少外侧上下文、预测最不准；加权窗自动压低块边权重，彻底消除整图热力图的网格拼缝。 |
| **多点位隔离交付 `deploy/`** | 最优模型产生时，在 `models/{产品}/deploy/{点位}/` 下分别拷贝各点位的 `{基准图名}.json`、基准图、`assets.jsonc`，并生成 `manifest.json` | 防止多点位同名配置文件互相覆盖，推理端读取 `manifest.json` 即可一键加载全点位要素。 |

## 五、 代码生成 JSON 格式说明（`deploy/manifest.json`）

`models/{产品}/deploy/manifest.json` 由训练引擎在刷新 `best` 时自动生成（标准纯 JSON）：

```json
{
  "weight": "best_int1200_ep10.pth",
  "tile_size": 512,
  "threshold": 0.5,
  "points": {
    "JXFB-1-P1": {
      "ref_name": "P1_1784621125487",
      "json": "JXFB-1-P1/P1_1784621125487.json",
      "ref_image": "JXFB-1-P1/P1_1784621125487.bmp",
      "assets": "JXFB-1-P1/assets.jsonc"
    }
  }
}
```

| 字段路径 | 类型 | 含义 |
| :--- | :--- | :--- |
| `weight` | `str` | 对应 `models/{产品}/` 下的最优权重文件名 |
