# NumPy API 完整手册（numpy_basics.py 专用版）

> 自包含参考：`stage0/numpy_basics.py` 用到的每一个 np 工具的作用、全部参数、可运行例子、在文件里的用途。例子都可在交互环境运行：`.venv/Scripts/python.exe`。

## 前置概念一：np 数组 = 数字表格

```python
np.array([[10, 20, 30],       # 2 行 3 列的表格
          [40, 50, 60]])      # 图像就是这种表格
```

np 的全部本事 = **不写循环，一次操作整张表格**。

## 前置概念二：参数的两种传法 + 类型（dtype）

```python
np.array([250, 100, 0], dtype=np.uint8)
     └──按顺序对号（位置参数）┘ └─指名道姓（关键字参数）─┘
```

`dtype`（data type）= 表格里装什么规格的数字：

| dtype | 大白话 | 范围 | 占地 |
|-------|--------|------|------|
| `np.uint8` | 0~255 整数（**图像标准**） | 0~255 | 1 字节 |
| `np.int32` | 普通整数（不指定时的**默认**） | ±21 亿 | 4 字节 |
| `np.float32` | 小数（单精度） | 很大 | 4 字节 |
| `np.float64` | 小数（双精度，linspace 的**默认**） | 更大 | 8 字节 |

uint8 装不下会**绕圈**：`np.array([250, 300, -5], dtype=np.uint8)` → `[250, 44, 251]`。涉及乘除小数必须：转 float → 算 → clip → 转回。

## 一、造表格（7 个）

### 1. `np.array(数据, dtype=类型)` —— 列表变 np 表格
- `数据`：嵌套列表长什么样表格就什么样；`dtype=`：不传则猜（整数→int32，小数→float64）。
```python
np.array([[10, 20], [30, 40]])
np.array([250, 100, 0], dtype=np.uint8)   # 明确用图像标准
```
文件里：演示段造溢出实验的小补丁。

### 2. `np.asarray(数据, dtype=类型)` —— 同上，但已是表格就不复制
- 参数与 `np.array` 相同；区别：`array` 总复制，`asarray` 能省则省。
文件里：`normalize` 把均值/方差列表转表格。

### 3. `np.arange(个数)` —— 造 0,1,2,…连续整数
```python
np.arange(5)   # -> [0, 1, 2, 3, 4]
```
文件里：棋盘格位置编号；视图演示造 0~11。

### 4. `np.linspace(起点, 终点, num=个数, dtype=类型)` —— 均匀撒点
- 起点/终点都**包含**；`num=` 个数（不传默认 50）。
```python
np.linspace(0, 10, num=3)   # -> [0., 5., 10.]
```
与 arange 的区别：**arange 管步长，linspace 管个数**。
文件里：造黑到白渐变横线 `linspace(0, 255, num=8)`。

### 5. `np.full(形状, 值, 类型)` —— 整表填同一个数
- `形状`：元组如 `(2,2)`；`值`：填什么；第 3 个位置参数 = dtype。
```python
np.full((2, 2), 7)   # -> [[7, 7], [7, 7]]
```
文件里：造 R/G/B 三张纯色片。

### 6. `np.tile(表格, (行份数, 列份数))` —— 复印铺贴
```python
np.tile([1, 2, 3], (2, 1))   # 竖铺 2 行横铺 1 列 -> [[1,2,3],[1,2,3]]
```
文件里：渐变横线复印 height 份变整张图。

### 7. `np.stack([表A, 表B, ...], axis=方向)` —— 同尺寸表叠一摞，多一个新维度
- `axis=-1` = 沿最后一根方向摞 → 新维落在最后。
```python
a = np.full((2, 2), 10); b = np.full((2, 2), 20)
np.stack([a, b], axis=-1)   # (2,2) 两张 -> (2,2,2)
```
文件里：三张 (2,2) 片摞成 (2,2,3) 彩色图。

## 三、切、摆、复制（4 个）

### 8. 切片 `表格[行起:行止, 列起:列止]`
- **含头不含尾**；逗号前管行、后管列；`:` 单独 = 全要；冒号边可写算式。
```python
a[0:2, 1:3]   # 第 0~1 行、第 1~2 列
a[1, :]       # 第 1 行整行
```
文件里：`crop_patch` 的 `image[y0:y0+size, x0:x0+size]`。

### 9. `[:, None]` / `[None, :]` —— 摆竖 / 摆横（插一根长 1 的新轴）
```python
np.arange(4)            # -> [0,1,2,3]        shape (4,) 原始一维
np.arange(4)[:, None]   # -> [[0],[1],[2],[3]] shape (4,1) 摆竖
np.arange(4)[None, :]   # -> [[0,1,2,3]]       shape (1,4) 摆横
```
文件里：棋盘格的"竖(64,1) + 横(1,64)"行列加法表。

### 10. `.reshape(行, 列)` —— 数字不变换摆法（总数必须不变）
```python
np.arange(12).reshape(3, 4)
```

### 11. `.copy()` —— 真复印件
- 切片默认是"窗户"（共享数据），copy 才独立。改切片块会污染原图！
```python
b = a[0:1, :]; c = a[0:1, :].copy(); a[0, 0] = 999
# b 跟着变 999，c 还是原值
```
文件里：`demo_view_vs_copy`。

## 四、逐元素运算（8 个）

### 12. `+ - * /` —— 整表一起算
```python
np.array([10, 20, 30]) * 2   # -> [20, 40, 60]
```

### 13. `//` 整除、`%` 取余
```python
np.array([3, 7, 8]) // 2   # -> [1, 3, 4]（商）
np.array([3, 7, 8]) % 2    # -> [1, 1, 0]（余数，奇偶判据）
```
文件里：`// cell` 归格、`% 2` 奇偶。

### 14. 比较运算 `> >= == < …` —— 逐格问，得对/错表
```python
np.array([10, 200, 30]) > 100   # -> [False, True, False]
```
对/错表可 `.mean()`（True 占比）、可转 0/1（二值化原理）。

### 15. `np.round(表)` —— 四舍五入
```python
np.round(np.array([36.4, 72.9]))   # -> [36., 73.]
```

### 16. `np.clip(表, 下限, 上限)` —— 超界拉回
```python
np.clip(np.array([250, 287.5, -3]), 0, 255)   # -> [250., 255., 0.]
```
文件里：调亮度安全带（287.5 → 255，不回绕成 31）。

### 17. `np.abs(表)` —— 抹掉负号
```python
np.abs(np.array([3, -5, 2]))   # -> [3, 5, 2]
```

### 18. `.astype(类型)` —— 换类型（⚠️ 砍小数，不四舍五入）
```python
np.array([1.7, 2.2]).astype(np.uint8)   # -> [1, 2]（1.7 砍成 1！）
```
安全三连顺序固定：**round → clip → astype**。

## 五、压缩汇总（2 个）

### 19. `.mean(axis=方向)` —— 平均；axis 写谁，谁就消失
- `axis` 可为数字或元组；**不传 = 全压成一个数**。
```python
m = np.array([[10, 20], [30, 40]])
m.mean(axis=0)   # 压行 -> 每列平均 [20., 30.]
m.mean(axis=1)   # 压列 -> 每行平均 [15., 35.]
m.mean()         # 25.0
```
文件里：`channel_means` 用 `axis=(0,1)` 压掉高和宽 → R/G/B 三个平均。

### 20. `np.unique(表)` —— 有哪几种不同的值
```python
np.unique(np.array([0, 255, 0, 255]))   # -> [0, 255]
```

## 六、按条件填值（1 个）

### 21. `np.where(对错表, 填A, 填B)` —— 对的填 A、错的填 B（逐格 if-else 一次完成）
```python
np.where(np.array([True, False, True]), 255, 0)   # -> [255, 0, 255]
```
文件里：棋盘格上色。常与比较运算连招：先比较得对错表、再 where 上色。

## 附：参数旋钮只有四大类

| 类别 | 长相 | 出现在 | 管什么 |
|------|------|--------|--------|
| 类型 | `dtype=…` | array/asarray/linspace/full | 装什么规格的数 |
| 形状 | 元组 `(2,2)`、`(height,1)` | full/tile/reshape | 多大、怎么铺 |
| 方向 | `axis=…` | stack/mean | 沿哪根轴摞/压 |
| 范围 | 两个裸数字 | clip 的 0,255；where 的 255,0 | 上下限、填什么 |

**必记 7 个**：`array`、切片、`+ *`、`mean(axis)`、`round+clip+astype 三连`、`copy`、`比较+where`。
